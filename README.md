# หารกัน

เว็บภาษาไทยสำหรับมือถือ คำนวณยอดจ่ายรายคนจากยอดสั่ง ค่าส่ง และส่วนลดรวม ใช้ HTML/CSS/JavaScript โดยไม่ต้องติดตั้ง dependencies

## ใช้งานในเครื่อง

```sh
npm start
```

เปิด http://localhost:4173 หรือเปิด `http://<IP ของคอมพิวเตอร์>:4173` จากมือถือที่อยู่ Wi-Fi เดียวกัน (ต้องอนุญาตพอร์ต 4173 ในไฟร์วอลล์)

## วิธีคำนวณ

ยอดสุทธิ = ผลรวมค่าสินค้า + ค่าส่ง − ส่วนลดรวม

ยอดของแต่ละคน = ยอดสุทธิ × ราคาสินค้าของคนนั้น / ผลรวมค่าสินค้า

คำนวณด้วยหน่วยสตางค์และ BigInt แบ่งเศษสตางค์ด้วยวิธี largest remainder เพื่อให้ยอดรายคนรวมตรงกับบิลเสมอ คนที่ไม่ได้สั่งสินค้า (0 บาท) จะไม่รับส่วนค่าส่งหรือส่วนลด ไม่อนุญาตส่วนลดมากกว่ายอดรวม และไม่คำนวณเมื่อค่าสินค้ารวมเป็นศูนย์


บันทึกบิลล่าสุดใน localStorage ของเบราว์เซอร์ ปุ่มเริ่มบิลใหม่ขอการยืนยันก่อนแทนข้อมูล ปุ่มคัดลอกมีหน้าต่างข้อความสำรองเมื่อ Clipboard API ใช้ไม่ได้

## ตรวจสอบ

```sh
npm test
```

ทดสอบความถูกต้องของบิล การปัดเศษ ยอดศูนย์ จำนวนที่ไม่ถูกต้อง และผลรวมของบิลตั้งแต่ 1–100 คน

ไฟล์เว็บไซต์พร้อมโฮสต์อยู่ใน `dist/`

## GitHub Pages

มีเครื่องคิดเลขส่วนลดในหน้าเดียว กดหัวข้อเพื่อกาง/พับ โดยเริ่มต้นพับไว้ และสูตรไม่หายเมื่อพับ รองรับบวก ลบ คูณ หาร เปอร์เซ็นต์ และพิมพ์วงเล็บได้ โดยคูณ/หารก่อนบวก/ลบ และ `%` หมายถึงหารด้วย 100 ผลลัพธ์คำนวณด้วยเศษส่วนอย่างแม่นยำแล้วปัดเป็นสตางค์ กด “ใช้ผลลัพธ์เป็นส่วนลดรวม” เพื่อแทนยอดส่วนลดในบิล ปุ่มเริ่มบิลใหม่จะล้างสูตรด้วย

เปิดใช้ผ่าน https://akkarapong821.github.io/harnkan/

เว็บเริ่มด้วยบิลว่าง ไม่มีข้อมูลสาธิต พร้อมบันทึกบิลที่กรอกไว้ในเบราว์เซอร์

เมื่อ push ไปยังสาขา main ระบบ GitHub Actions จะทดสอบและเผยแพร่ไฟล์ใน dist/ ไปยัง GitHub Pages อัตโนมัติ ตั้งค่า Settings → Pages → Source เป็น GitHub Actions
